# Gym Fitness Web Application

A responsive fitness web application that helps users explore workouts and maintain a healthy lifestyle.

## Features

- Browse different workout exercises
- Responsive UI for desktop and mobile
- Built with modern React components
- Fast development using Vite

## Tech Stack

- React
- Vite
- HTML
- CSS
- JavaScript

## Installation

Clone the repository:

git clone https://github.com/Abhinab27/gym_fitness.git

Go to the project folder:

cd gym_fitness

Install dependencies:

npm install

Run the project:

npm run dev
